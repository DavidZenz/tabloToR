| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-18 | Tampering | baseline refresh and acceptance | high | mitigate | Separate proposal/check from acceptance, reject canonical output targets, require reviewer/reason/date/hash evidence, and test canonical immutability. |
| T-02-19 | Information Disclosure | fingerprints and metadata | medium | mitigate | Hash only approved source/fixture scope, omit private inputs and full solutions, and document volatile metadata separately from canonical expectations. |
| T-02-20 | Denial of Service | proposal file handling | medium | mitigate | Normalize paths and bound input/output sizes before reading or allocating; reject oversized fixtures and unsafe roots. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager installs are planned; any future install requires a package-legitimacy gate and blocking human verification. |
