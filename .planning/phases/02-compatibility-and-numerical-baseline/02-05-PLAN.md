<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| serialization file -> payload validator | Local artifact contents cross into schema and type validation. |
| validated payload -> model reconstruction | Portable state is installed into a new model and may allocate compiler/cache structures. |
| restored model -> native backend | Rebuilt optional pointers/factors cross into native wrappers only after capability checks. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-15 | Tampering | versioned payload/schema | high | mitigate | Allowlist schema/fields, validate types/dimensions/finiteness/source fingerprint/size before reconstruction; reject unknown or incompatible payloads without mutation. |
| T-02-16 | Denial of Service | payload and source reconstruction | medium | mitigate | Bound payload/file/model sizes and sparse dimensions before allocation; keep native/cache rebuild lazy. |
| T-02-17 | Information Disclosure | serialized model state | medium | mitigate | Document trusted-local-artifact boundary, exclude private transient/native state, and test that only portable logical fields are emitted. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager installs are planned; any future install requires a package-legitimacy gate and blocking human verification. |

ASVS L1 block: schema-validation or safe-deserialization failure is high severity and blocks the phase.
</threat_model>
