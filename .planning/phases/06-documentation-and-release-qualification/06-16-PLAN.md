<objective>
Establish local, supported-runtime evidence for the reported predecessor/leaf serialization assertions and prepare a digest-bound proposal only for a reproduced behavior failure.

Purpose: Source-mode checks do not establish serialization behavior on the newer R/Matrix context that exposed the hosted failures. This plan narrows execution to the relevant predecessor, leaf round-trip, malformed-leaf, and BUGFIX groups without starting CI or claiming a hosted result.
Output: Isolated local results and, only if a focused behavior assertion reproduces while the existing approved BUGFIX gate passes, a retained proposal with exact before/after/patch and test digests. This plan never applies the proposal or changes canonical source, tests, DCF, or patch files. The proposal awaits a separate user approval and follow-up plan; the hosted behavior-unverified item remains open until an authorized hosted run completes.
</objective>
