<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Selected evidence root to release decision | Fixed authority, provenance, citation, repository, and package files can be replaced by symlinks outside the selected root. |
| Selected evidence root to R validator loader | A tool script path is sourced as executable R code and can run with the gate process's permissions. |
| Canonical root containment to filesystem-root evidence | A duplicate separator can reject valid files under `/` or a Windows drive root, causing availability failure. |
