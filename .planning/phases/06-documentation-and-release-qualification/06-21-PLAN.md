| Benchmark process to public evidence | Only reviewed aggregate metrics and approved fingerprints enter the result document. |
| Operator to independent reviewer | The evidence producer cannot approve their own benchmark result. |

| T-06-21-02 | Tampering | Reference/candidate comparison | high | mitigate | Verify exact source/package/compiler/environment metadata and run the existing checker unchanged. |
