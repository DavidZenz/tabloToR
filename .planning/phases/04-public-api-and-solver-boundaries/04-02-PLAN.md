## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller options to adapter registry | Backend IDs and native thread requests select an implementation and capability path. |
| Package code to native registration | R callbacks rely on registered symbols, wrapper arities, ABI metadata, and native capabilities. |
| Native resources to model state | Per-solve factors and buffers must not outlive their solve or cross the accepted-state boundary. |

| T-04-03 | Tampering / Denial of Service | Rcpp symbols, ABI, kernels, and thread limits | high | mitigate | Verify symbols, arities, ABI, capability payload, deterministic Matrix self-test, and thread limits before solving; fail closed and release resources through cleanup callbacks. |
</threat_model>
