<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Versioned evidence/base evaluator → integrated result | Unsupported or absent integration state could bypass all downstream checks. |
| Source/Git tree → provenance ledger | Mutable documents could conceal source deletion, addition, or expression drift. |
| Public destinations/license decision → release readiness | Missing credit or an unreviewed/invalid license could be promoted to release metadata. |
| Fixture/evidence paths → filesystem/process | Path escape, sensitive files, or unsafe diagnostics could cross the evaluated root. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-038 | Elevation of privilege | integrated version fallback | critical | mitigate | Validate exact marker cardinality/value before base eligibility is consulted. |
| T-01-039 | Tampering | source/provenance binding | critical | mitigate | Fresh extraction with Git evidence and shared exact key/hash/review validation. |
| T-01-040 | Tampering | attribution destinations | high | mitigate | Open all six destinations and require exact reviewed role/key parity in production. |
| T-01-041 | Spoofing | dependency/license decision | high | mitigate | Bind exact expression to an under-root reviewed audit artifact/hash and R's license checker. |
| T-01-042 | Information disclosure | diagnostics/fixtures | high | mitigate | Stable reason codes only; synthetic small fixtures; retain no matched contents or sensitive paths. |
| T-01-043 | Repudiation | reviewer/date evidence | medium | mitigate | Exact status, reviewer, round-tripped date, and hash-bound decision/report records. |
| T-01-044 | Denial of service | source extraction/license validation | medium | mitigate | Bound evaluated roots/inputs and fail explicitly on tool/parser errors. |
</threat_model>
