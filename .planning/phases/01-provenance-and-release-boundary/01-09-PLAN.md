| Boundary | Description |
|----------|-------------|
| Native source bytes → normalized expression hash | Token erasure or ambiguous normalization can hide behavior changes. |
| Old ledger → re-reviewed ledger | Automated migration can improperly preserve approvals or alter ownership facts. |
| Git/hash evidence → attribution | Technical evidence can be over-promoted into unsupported authorship or rights claims. |
