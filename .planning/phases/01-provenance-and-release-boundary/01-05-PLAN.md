## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Reviewed provenance ledger → role decisions | Heuristic Git evidence could be promoted to unsupported authorship or ownership claims. |
| Attribution record → package/public docs | Drift could erase or invent credit across destinations. |
| Private evidence → contributor/public records | Correspondence, proprietary inputs, or unapproved contacts could leak. |

| T-01-014 | Tampering | attribution destinations | high | mitigate | Direct independent schema, link, and parity tests across all D-08/D-09 files. |
