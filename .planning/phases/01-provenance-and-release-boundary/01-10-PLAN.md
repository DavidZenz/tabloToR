<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Component Markdown → filesystem | Untrusted relative paths or symlinks could escape the evaluated evidence root. |
| Replacement/test/fixture bytes → independent result | Hash or key drift could make a stale result appear current. |
| Behavior test → R subprocess | Repository-controlled test code executes during a release decision. |
| Role attestations → clean-room eligibility | One actor could self-declare incompatible independent roles. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-045 | Elevation of privilege | evidence path resolution | critical | mitigate | Normalize real paths, require under-root regular files, and reject traversal/symlink escape before reading/executing. |
| T-01-046 | Tampering | source/test/fixture/result hashes | high | mitigate | Exact MD5 parity at component and independent-result layers plus fresh test execution. |
| T-01-047 | Spoofing | independent result producer | high | mitigate | Pairwise role constraints and result metadata bound to component/key/hashes. |
| T-01-048 | Repudiation | clean-room review | high | mitigate | Required attestations, reviewer/date, test command/status, and immutable result artifact hash. |
| T-01-049 | Denial of service | behavior test subprocess | medium | mitigate | One fixed Rscript invocation per bounded component, captured output, and explicit nonzero/error failure. |
| T-01-050 | Information disclosure | external/sensitive fixture path | high | mitigate | Reject root escape and sensitive classes; diagnostics emit reason codes without paths/contents. |
</threat_model>
