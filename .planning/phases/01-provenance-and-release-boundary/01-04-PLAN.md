<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote indexes/search → local name evidence | Time-varying or malformed responses enter a collision decision. |
| Local identity hints → approved public metadata | Git remotes/emails must not substitute for human approval. |
| Governance/runbook → external GitHub state | Documentation must not authorize mutation by itself. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-016 | Spoofing | registry/search sources | medium | mitigate | Fixed endpoints, UTC timestamps, hashes, source availability, exact-match rules, and signed review. |
| T-01-017 | Tampering | stale/partial name report | high | mitigate | All six rows plus fresh reservation/release check kinds and verifier signatures. |
| T-01-018 | Information disclosure | approved contact/security route | high | mitigate | Blocking human approval before committed public values. |
| T-01-019 | Elevation of privilege | repository/release actions | high | mitigate | Explicit not-authorized markers and separate fresh blocking-human checkpoints. |
| T-01-020 | Repudiation | identity approval | medium | mitigate | Record exact values, reviewer, UTC date, and cross-document parity. |
</threat_model>
